# Stack Queue Exercise

## English

This repository contains simple Java implementations of two basic data structures:

- Stack
- Queue

The project is intended as a small exercise for practicing array-based data structure logic in Java.

### Files

- `Main.java` demonstrates basic stack and queue operations.
- `Stack.java` contains an array-based stack implementation.
- `Queue.java` contains an array-based queue implementation.

### How to Run

Compile the Java files:

```bash
javac Main.java Stack.java Queue.java
```

Run the demo:

```bash
java Main
```
